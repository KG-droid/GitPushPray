Lloyds Bank black horse logo (green tile), as published on Wikimedia (`Lloyds_Bank_logo_2024.svg`). The green tile reads well on both the light and dark themes, so one file serves both.

- `lloyds-logo.svg`: used in both themes.
- `lloyds-logo-dark.svg`: optional. If added, `src/components/BrandMark.tsx` uses it in the dark theme instead.
